## 1. 프로젝트 개요
---
### 한 줄 정의
영어 단어 멀티미디어 학습 콘텐츠

### 제품 목표
고등학교 기초 영어 단어를 초등학교 6학년 남자아이가 흥미롭게 이해하고 기억하도록, 쉬운 영영 뜻·관심사 기반 영어 예문·이미지·짧은 영상으로 구성된 학습 콘텐츠를 빠르게 만든다.

### 배경
1200개 수준의 단어 목록에는 한글 뜻만 있어 학습자가 단어의 실제 쓰임과 장면을 연결하기 어렵다. 게임, 코딩, 인공지능, 소설쓰기, 음악, 스포츠처럼 학습자가 좋아하는 소재를 활용하고, 같은 예문을 이미지와 영상으로 확장할 수 있는 일관된 콘텐츠 생성 흐름이 필요하다.

### 사용자 문제
학습자는 단어의 한글 뜻만으로는 의미와 사용 맥락을 오래 기억하기 어렵고, 어려운 예문은 학습 의욕을 떨어뜨릴 수 있다. 콘텐츠 제작자는 1200개 단어에 맞는 쉬운 영영 뜻, 자연스러운 예문, 시각 자료용 프롬프트를 일관된 품질로 작성하는 데 많은 시간이 든다.

### 해결 방안
CSV의 영어 단어와 한글 뜻을 입력으로 받아 단어별 쉬운 영영사전식 뜻과 초등학교 6학년 수준의 영어 예문을 만든다. 여러 의미나 품사가 가능한 단어는 입력된 한글 뜻과 일반적인 사용 빈도를 우선해 AI가 대표 의미와 품사를 정한 뒤, 그 결정값으로 예문과 이미지·8초 영상 프롬프트를 일관되게 생성한다. 예문 주제는 게임·코딩·인공지능·소설쓰기·음악·스포츠로 구성된 관심사 묶음과 초등학교 6학년 사회·과학으로 구성된 학습 묶음을 번갈아 배정하며, 단어 뜻에 맞지 않는 주제는 건너뛰고 해당 묶음의 다음 적합한 주제를 선택한다.

### 차별점
단순 번역이나 예문 생성에 그치지 않고, 학습자의 구체적인 관심사와 읽기 수준을 기준으로 예문 주제를 설계한다. 이미지와 영상이 예문 속 핵심 행동·사물·분위기를 일관되게 보여 주도록 하나의 예문에서 연결된 생성 프롬프트를 제공한다.

### 타겟 사용자
주 사용자는 게임, 간단한 코딩, 인공지능 사용, 소설쓰기, 피아노 등 음악, 스포츠와 초등학교 6학년 사회·과학 학습 주제에 관심이 있는 초등학교 6학년 남자아이다. 콘텐츠 제작자 또는 보호자는 고등학교 기초 영어 단어 목록을 바탕으로 학습자의 흥미와 수준에 맞는 멀티미디어 학습 자료를 대량으로 준비하려는 사람이다.

### 사용자 시나리오
콘텐츠 제작자는 단어와 한글 뜻이 담긴 CSV 파일을 준비하고, 예문 주제는 관심사 묶음과 학습 묶음을 번갈아 배정하도록 설정한다. 서비스는 단어 뜻에 맞지 않는 주제를 건너뛰고 해당 묶음의 다음 적합한 주제를 선택해 영영 뜻과 예문을 만들며, 예문 장면에 맞는 이미지·8초 영상 생성 프롬프트를 함께 제공한다. 학습자는 단어 뜻을 읽고 예문·이미지·영상을 연결해 보며 단어의 의미와 사용 장면을 익힌다.

### 핵심 지표
1200개 단어 중 영영 뜻·영어 예문·이미지 프롬프트·8초 영상 프롬프트가 모두 완성된 단어의 비율을 측정한다. 예문이 목표 단어를 정확히 포함하고 초등학교 6학년 수준의 문장으로 검토 통과한 비율, 관심사 묶음과 학습 묶음이 번갈아 배정된 비율, 단어 뜻에 맞지 않아 주제를 건너뛴 항목의 비율, 유해 콘텐츠 제한 때문에 대체 장면으로 수정된 항목의 비율, 재생성 대기 목록에 남은 실패 항목의 비율을 확인한다.

### 리스크
단어의 품사나 여러 의미가 한글 뜻만으로 충분히 구분되지 않을 때는 입력된 한글 뜻과 일반적인 사용 빈도를 우선해 AI가 대표 의미와 품사를 정한다. 이 결정으로 만든 예문과 시각 프롬프트는 같은 의미를 기준으로 연결하고, 의미가 부정확한 항목은 품질 검토에서 수정 대상으로 표시한다. 단어 뜻에 맞는 주제가 특정 묶음에 부족할 경우 묶음 순환 규칙이 일부 건너뛰어질 수 있으므로, 실제 배정 순서와 건너뛴 사유를 검토한다. 이미지·영상 프롬프트가 유해 콘텐츠 제한에 걸릴 가능성이 있으면 핵심 단어 의미를 유지한 채 직접적 표현을 은유적·안전한 장면으로 바꾸거나 동물을 활용한 장면으로 대체한다. 대체 후에도 생성할 수 없는 항목은 실패 사유와 마지막 시도를 재생성 대기 목록에 기록한다. 저작권이 있는 게임의 고유 캐릭터·로고를 직접 재현하지 않고 일반적인 게임 장면으로 표현하는 기준이 필요하다.

### 4.1 예문 기반 이미지 프롬프트 작성

콘텐츠 제작자는 영어 예문의 한 장면을 그림으로 만들 수 있도록 이미지 생성 프롬프트를 작성한다. 프롬프트는 인물, 행동, 핵심 사물, 배경, 밝고 안전한 분위기를 포함하며, 유해 콘텐츠 제한에 걸릴 가능성이 있으면 단어 의미를 유지한 은유적 표현이나 동물이 등장하는 안전한 장면으로 바꾼다. 이미지 생성 실행은 포함하지 않는다.


### 4.2 예문 기반 8초 영상 프롬프트 작성
> **중요도**: 🔴 높음 | **진행 상태**: ⚪ 작성중

콘텐츠 제작자는 영어 예문의 핵심 행동이 8초 안에 드러나도록 영상 생성 프롬프트를 작성한다. 프롬프트는 시작 장면, 짧은 움직임, 안전한 마무리 장면을 간결하게 정하고, 유해 콘텐츠 제한에 걸릴 가능성이 있으면 단어 의미를 유지한 은유적 표현이나 동물이 등장하는 안전한 장면으로 바꾼다. 음성 대사나 영상 편집은 포함하지 않는다.

## 5. 콘텐츠 품질 검토
> **중요도**: 🟡 중간 | **진행 상태**: ⚪ 작성중

콘텐츠 제작자는 대량 생성된 단어 콘텐츠의 의미 정확성, 학습자 적합성, 주제 분포, 프롬프트 일관성을 확인하고 보완한다. AI가 대표 의미와 품사를 정한 단어는 예문과 시각 프롬프트가 그 기준에 맞는지 우선 확인하며, 관심사 묶음과 학습 묶음의 순환 배정 여부 및 건너뛬 사유도 점검한다. 유해 콘텐츠 제한에 걸린 시각 프롬프트는 안전한 대체 장면 적용 여부를 확인하고, 대체 후에도 생성할 수 없는 항목은 재생성 대기 목록으로 보낸다. 자동 수정이나 학습자의 실제 정답률 분석은 이 범위에 포함하지 않는다.

**수용 기준:**
```
1. ○ 단어별 필수 결과물의 완성 여부를 확인할 수 있다.
2. ○ 목표 단어의 의미와 예문 사용이 맞지 않는 항목을 식별할 수 있다.
3. ○ 안전한 대체 장면을 적용한 뒤에도 생성할 수 없는 항목은 실패 사유와 함께 재생성 대기 목록에 기록된다.
```


### 5.1 콘텐츠 완성도 점검
> **중요도**: 🟡 중간 | **진행 상태**: ⚪ 작성중

콘텐츠 제작자는 단어별 필수 결과물의 누락 여부와 단어 의미·예문·시각 프롬프트의 연결성을 점검한다. AI가 정한 대표 의미와 품사에 예문·이미지·영상 프롬프트가 맞는지, 관심사 묶음과 학습 묶음이 번갈아 배정됐는지, 주제를 건너뛴 사유가 기록됐는지 확인한다. 유해 콘텐츠 제한에 걸린 시각 프롬프트는 안전한 대체 장면 적용 여부를 확인하고, 대체 후에도 생성할 수 없는 항목은 실패 사유와 마지막 시도 내용을 재생성 대기 목록에 표시한다.

## 6. 생성 실패 항목 관리
> **중요도**: 🟡 중간 | **진행 상태**: ⚪ 작성중

콘텐츠 제작자는 안전한 대체 장면을 적용한 뒤에도 이미지나 영상 프롬프트를 만들 수 없는 단어를 재생성 대기 목록으로 관리한다. 목록에는 단어, 실패한 산출물, 실패 사유, 마지막 시도 내용을 기록해 이후 재생성 대상을 확인할 수 있으며, 자동 재생성 실행이나 외부 문서 저장 방식은 이 범위에 포함하지 않는다.

**수용 기준:**
```
1. ○ 생성에 실패한 단어와 실패한 산출물을 재생성 대기 목록에서 확인할 수 있다.
2. ○ 각 실패 항목에 실패 사유와 마지막 시도 내용이 기록된다.
3. ○ 콘텐츠 제작자가 재생성 대기 목록에서 다시 만들 대상을 구분할 수 있다.
```
