# 영어 단어 멀티미디어 학습 콘텐츠 생성 계획

## 1. 프로젝트 개요

### 1.1 목적
고등학교 기초 영어 단어 (약 1,200 개) 를 초등학교 6학년 학습자의 수준과 관심사에 맞춰 이미지와 짧은 영상으로 학습할 수 있는 멀티미디어 학습 콘텐츠를 생성한다.

### 1.2 목표 사용자
- **학습자**: 게임, 코딩, 인공지능, 소설 쓰기, 음악, 스포츠, 초등학교 6학년 사회·과학에 관심이 있는 초등학교 6학년 남자아이
- **콘텐츠 제작자**: 대량으로 학습 자료를 제작하려는 사용자
- **보호자**: 학습 콘텐츠를 검토하고 확인하는 사용자

---

## 2. 입력 데이터 분석

### 2.1 소스 데이터
- **파일**: `hackers_voca.csv`
- **구성**: DAY 01~DAY 30, 각 DAY 당 약 40 개 단어
- **총 단어 수**: 약 1,200 개
- **컬럼**: `DAY`, `no.`, `단어`

### 2.2 데이터 특성
- 한글 뜻이 포함되어 있지 않아 별도 한영 사전 또는 API 연동 필요
- DAY 별 학습 단위로 구분되어 있음
- 고등학교 기초 수준의 영어 단어 목록

---

## 3. 생성 산출물 명세

각 단어당 다음 13 개 항목을 생성한다:

| # | 필드명 | 설명 |
|---|--------|------|
| 1 | `word` | 영어 단어 |
| 2 | `korean_meaning` | 한글 뜻 (외부 사전 참조) |
| 3 | `selected_pos` | 대표 품사 (명사, 동사, 형용사 등) |
| 4 | `selected_meaning` | 대표 의미 (여러 의미 중 우선순위 적용) |
| 5 | `english_definition` | 쉬운 영영사전식 뜻 (초등 6 학년 수준) |
| 6 | `example_sentence` | 영어 예문 (목표 단어 포함, 초등 6 학년 수준) |
| 7 | `example_translation` | 예문 한글 해석 |
| 8 | `topic_group` | 주제 묶음 (관심사/학습) |
| 9 | `assigned_topic` | 실제 배정된 주제 |
| 10 | `skipped_topics` | 건너뛴 주제 목록 |
| 11 | `skip_reason` | 주제 건너뛴 사유 |
| 12 | `image_prompt` | 이미지 생성 프롬프트 |
| 13 | `video_prompt` | 8 초 영상 생성 프롬프트 |
| 14 | `safety_replaced` | 안전한 장면 대체 여부 |
| 15 | `quality_status` | 품질 검토 상태 |
| 16 | `generation_status` | 생성 성공/실패 상태 |
| 17 | `retry_count` | 재생성 시도 횟수 |
| 18 | `failure_reason` | 실패 사유 |
| 19 | `manual_review` | 수동 검토 필요 여부 |

## 4. 주제 배정 규칙

### 4.1 주제 묶음

#### 관심사 묶음 (6 개)
1. 게임
2. 코딩
3. 인공지능
4. 소설 쓰기
5. 음악
6. 스포츠

#### 학습 묶음 (2 개)
1. 초등학교 6 학년 사회
2. 초등학교 6 학년 과학

### 4.2 배정 순서
- 관심사 묶음과 학습 묶음을 **번갈아 배정**
- 예시: 게임 → 사회 → 코딩 → 과학 → 인공지능 → 사회 → ...

### 4.3 주제 건너뛰기 규칙
1. 현재 주제가 단어 뜻과 부적합하면 같은 묶음의 다음 주제로 이동
2. 적합한 주제를 찾을 때까지 묶음 안에서 순환
3. 건너뛴 주제와 사유 기록
4. 해당 묶음에 적합한 주제가 없으면 다른 묶음 임시 사용 가능

## 5. 콘텐츠 생성 기준

### 5.1 영영 뜻 생성
- 초등학교 6 학년이 이해할 수 있는 쉬운 영어 사용
- 정의 안에 목표 단어 자체를 반복하지 않음
- 선택된 대표 의미와 품사에 일치

### 5.2 영어 예문 생성
- 목표 단어를 정확히 포함
- 문법적으로 자연스러움
- 초등학교 6 학년 수준의 어휘와 문장 구조
- 이미지·영상으로 표현 가능한 구체적인 장면 포함
- 저작권 있는 캐릭터·로고·게임 이름 사용 금지

### 5.3 이미지 프롬프트 생성
- 예문의 핵심 장면을 한 장의 이미지로 표현
- 핵심 인물, 사물, 행동 포함
- 목표 단어의 의미가 시각적으로 드러남
- 안전한 장면 구성
- 복잡한 배경보다 핵심 의미 중심

### 5.4 영상 프롬프트 생성 (8 초)

| 구간 | 내용 |
|------|------|
| 0~2 초 | 인물, 장소, 핵심 사물 소개 |
| 2~6 초 | 목표 단어의 의미를 보여 주는 핵심 행동 |
| 6~8 초 | 행동의 결과 또는 의미를 강조하는 마무리 |

- 이미지 프롬프트와 동일한 인물·사물·장소 사용
- 장면 전환 최소화
- 8 초 안에 이해 가능한 단순한 흐름

## 6. 품질 검증 기준

### 6.1 자동 검증 항목
- [ ] 목표 단어가 예문에 포함되었는지
- [ ] 선택한 품사로 사용되었는지
- [ ] 입력된 한글 뜻과 예문 의미가 일치하는지
- [ ] 문장 난도가 초등학교 6 학년 수준인지
- [ ] 문법적으로 자연스러운지
- [ ] 예문과 이미지 프롬프트가 일치하는지
- [ ] 예문과 영상 프롬프트가 일치하는지
- [ ] 주제 배정 순서가 올바른지
- [ ] 유해·부적절한 내용이 없는지
- [ ] 저작권 있는 고유 캐릭터·로고가 없는지

### 6.2 완료 조건
다음 조건을 모두 만족하면 완료로 판단:
- 대표 의미와 품사가 결정됨
- 쉬운 영영 뜻이 생성됨
- 목표 단어가 포함된 영어 예문이 생성됨
- 예문 한글 해석이 생성됨
- 이미지 생성 프롬프트가 생성됨
- 8 초 영상 생성 프롬프트가 생성됨
- 예문, 이미지, 영상이 같은 의미와 장면을 사용함
- 안전성 검토를 통과함
- 저작권·상표권 문제가 없음

## 7. 리스크 관리

### 7.1 단어 의미·품사 불확실성
- **리스크**: 한글 뜻만으로 품사·의미 구분 어려움
- **대응**: 
  - 입력된 한글 뜻 우선 적용
  - 일반적 사용 빈도 높은 의미 보조 기준
  - 신뢰도 낮은 항목은 품질 검토 대상 표시

### 7.2 주제 배정 부자연스러움
- **리스크**: 단어가 배정 주제와 연결되지 않음
- **대응**:
  - 부적합 주제 억지로 사용 금지
  - 같은 묶음 내 다음 주제 사용
  - 실제 배정 순서와 건너뛴 사유 기록

### 7.3 유해 콘텐츠 제한
- **리스크**: 안전 기준에 걸리는 장면
- **대응**:
  - 핵심 의미 유지하며 은유적 표현으로 변경
  - 사람 대신 동물·사물 활용
  - 대체 불가 시 실패 사유 기록 후 재생성 대기

### 7.4 저작권·상표권 문제
- **리스크**: 게임·애니메이션 캐릭터·로고 포함
- **대응**:
  - 실제 게임 이름·고유 캐릭터 이름 사용 금지
  - 일반적인 판타지·블록·레이싱 게임 등으로 표현
  - 프롬프트 생성 후 고유명사 자동 검사

### 7.5 대량 생성 품질 편차
- **리스크**: 1,200 개 단어 품질 편차 발생
- **대응**:
  - 일정한 생성 템플릿 사용
  - 단어별 자동 검증 적용
  - 일정 단위 나누어 생성 및 품질 확인
  - 반복 실패 항목은 수동 검토 대상 전환

## 8. 작업 단계

### Phase 1: 데이터 준비
1. CSV 파일 파싱 및 단어 목록 추출
2. 한글 뜻 매핑 (한영 사전 API 또는 로컬 사전)
3. 대표 품사·의미 결정 로직 구현

### Phase 2: 콘텐츠 생성
1. 영영 뜻 생성 (초등 6 학년 수준)
2. 영어 예문 생성 (주제 배정 적용)
3. 예문 한글 해석 생성
4. 이미지 프롬프트 생성
5. 8 초 영상 프롬프트 생성

### Phase 3: 품질 검증
1. 자동 검증 루틴 실행
2. 실패 항목 식별 및 분류
3. 재생성 대기 목록 작성

### Phase 4: 재생성 및 최종화
1. 재생성 대상 재처리
2. 수동 검토 필요 항목 선별
3. 최종 CSV 출력

## 12. 참고 사항

- 생성된 콘텐츠는 웹 브라우저, 태블릿, 스마트폰에서 열람 가능해야 함
