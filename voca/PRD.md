# PRD: 영어 단어 멀티미디어 학습 콘텐츠

## 1. 개요

### 1.1 한 줄 정의

고등학교 기초 영어 단어를 초등학교 6학년 학습자의 수준과 관심사에 맞춰 이미지와 짧은 영상으로 학습할 수 있도록 만드는 멀티미디어 학습 콘텐츠 생성 서비스

---

## 2. 제품 목표

고등학교 기초 수준의 영어 단어를 초등학교 6학년 남자아이가 흥미롭게 이해하고 오래 기억할 수 있도록 다음 요소로 구성된 학습 콘텐츠를 빠르게 제작한다.

* 쉬운 영영 뜻
* 학습자 관심사 기반의 영어 예문
* 예문 장면을 표현한 이미지 생성 프롬프트
* 예문 장면을 표현한 8초 영상 생성 프롬프트

---

## 3. 배경

약 1,200개 수준의 영어 단어 목록에는 현재 한글 뜻만 포함되어 있다.

학습자가 한글 뜻만 읽는 방식으로 공부할 경우 단어의 실제 사용 맥락과 구체적인 장면을 연결하기 어렵고, 시간이 지나면 의미를 기억하기도 어렵다.

학습자가 좋아하는 다음 소재를 활용하면 단어 학습에 대한 흥미와 이해도를 높일 수 있다.

### 관심사 주제

* 게임
* 코딩
* 인공지능
* 소설 쓰기
* 음악
* 스포츠

### 학습 주제

* 초등학교 6학년 사회
* 초등학교 6학년 과학

또한 하나의 영어 예문을 이미지와 영상 콘텐츠로 확장할 수 있도록, 예문과 시각 자료 사이에 일관성이 유지되는 콘텐츠 생성 흐름이 필요하다.

---

## 4. 문제 정의

### 4.1 학습자의 문제

* 단어의 한글 뜻만으로는 의미와 실제 사용 맥락을 오래 기억하기 어렵다.
* 단어가 사용되는 상황을 구체적인 장면으로 떠올리기 어렵다.
* 예문이 지나치게 어렵거나 학습자의 관심사와 관련이 없으면 학습 의욕이 떨어질 수 있다.
* 예문, 이미지, 영상의 내용이 서로 다르면 단어와 장면을 연결하기 어렵다.

### 4.2 콘텐츠 제작자의 문제

* 약 1,200개 단어마다 적절한 영영 뜻과 예문을 직접 작성하는 데 많은 시간이 든다.
* 단어별로 초등학교 6학년 수준에 맞는 자연스러운 예문을 일관되게 작성하기 어렵다.
* 여러 의미나 품사를 가진 단어의 대표 의미를 결정하기 어렵다.
* 예문과 일치하는 이미지 및 영상 생성 프롬프트를 별도로 작성해야 한다.
* 대량 생성 과정에서 품질, 주제 배정, 안전성, 실패 항목을 체계적으로 관리하기 어렵다.

---

## 5. 해결 방안

CSV 파일에 포함된 영어 단어와 한글 뜻을 입력받아 단어별 학습 콘텐츠를 자동으로 생성한다.

### 5.1 기본 생성 항목

각 단어에 대해 다음 항목을 생성한다.

1. 영어 단어
2. 입력된 한글 뜻
3. 대표 품사
4. 선택된 대표 의미
5. 쉬운 영영사전식 뜻
6. 초등학교 6학년 수준의 영어 예문
7. 예문 한글 해석
8. 예문 주제
9. 이미지 생성 프롬프트
10. 8초 영상 생성 프롬프트
11. 주제 건너뛰기 여부와 사유
12. 안전한 장면으로 대체했는지 여부
13. 생성 상태 및 실패 사유

### 5.2 대표 의미 및 품사 결정

하나의 단어에 여러 의미나 품사가 존재하는 경우 다음 순서로 대표 의미와 품사를 결정한다.

1. CSV에 입력된 한글 뜻을 가장 우선한다.
2. 입력된 한글 뜻에 가장 잘 맞는 품사를 선택한다.
3. 여러 후보가 남으면 일반적인 영어 사용 빈도가 높은 의미를 우선한다.
4. 선택한 대표 의미와 품사를 영영 뜻, 예문, 이미지 프롬프트, 영상 프롬프트에 동일하게 적용한다.
5. 의미가 불분명하거나 정확도가 낮은 항목은 품질 검토 대상으로 표시한다.

### 5.3 예문 생성 기준

예문은 다음 기준을 만족해야 한다.

* 목표 단어를 정확히 포함한다.
* 선택된 대표 의미와 품사에 맞게 사용한다.
* 초등학교 6학년이 이해할 수 있는 어휘와 문장 구조를 사용한다.
* 지나치게 길거나 복잡한 문장을 피한다.
* 문법적으로 자연스러워야 한다.
* 단어의 의미를 문맥에서 추론할 수 있어야 한다.
* 이미지와 짧은 영상으로 표현 가능한 구체적인 장면을 포함한다.
* 저작권이 있는 캐릭터, 로고, 게임 이름을 직접 사용하지 않는다.

## 6. 예문 주제 배정 규칙

### 6.1 주제 묶음

예문 주제는 다음 두 개의 묶음으로 관리한다.

#### 관심사 묶음

1. 게임
2. 코딩
3. 인공지능
4. 소설 쓰기
5. 음악
6. 스포츠

#### 학습 묶음

1. 초등학교 6학년 사회
2. 초등학교 6학년 과학

### 6.2 묶음 교차 배정

단어마다 관심사 묶음과 학습 묶음을 번갈아 배정한다.

예시:

| 단어 순서 | 배정 묶음  | 예시 주제 |
| ----: | ------ | ----- |
|     1 | 관심사 묶음 | 게임    |
|     2 | 학습 묶음  | 사회    |
|     3 | 관심사 묶음 | 코딩    |
|     4 | 학습 묶음  | 과학    |
|     5 | 관심사 묶음 | 인공지능  |
|     6 | 학습 묶음  | 사회    |

### 6.3 부적합 주제 건너뛰기

현재 선택된 주제가 단어 뜻과 자연스럽게 연결되지 않는 경우 해당 주제를 억지로 사용하지 않는다.

다음 절차에 따라 주제를 선택한다.

1. 현재 묶음에서 다음 순서의 주제를 확인한다.
2. 단어 의미와 자연스럽게 연결할 수 있는지 평가한다.
3. 부적합하면 같은 묶음의 다음 주제로 이동한다.
4. 적합한 주제를 찾을 때까지 묶음 안에서 순환한다.
5. 건너뛴 주제와 건너뛴 사유를 기록한다.
6. 해당 묶음에 적합한 주제가 없으면 다른 묶음을 임시로 사용할 수 있다.
7. 묶음 전환이 발생한 경우 실제 배정 결과와 전환 사유를 기록한다.

## 7. 멀티미디어 콘텐츠 생성

### 7.1 이미지 생성 프롬프트

이미지 생성 프롬프트는 영어 예문의 핵심 장면을 한 장의 이미지로 표현해야 한다.

#### 필수 기준

* 예문에 등장하는 핵심 인물, 사물, 행동을 포함한다.
* 목표 단어의 의미가 시각적으로 드러나야 한다.
* 초등학교 6학년 학습자에게 적합한 안전한 장면이어야 한다.
* 복잡한 배경보다 핵심 의미가 잘 보이는 구성을 우선한다.
* 저작권이 있는 캐릭터, 로고, 게임 화면을 직접 재현하지 않는다.
* 일반적인 게임, 코딩, 음악, 스포츠 장면으로 표현한다.
* 예문과 다른 행동이나 설정을 추가하지 않는다.

### 7.2 8초 영상 생성 프롬프트

영상 생성 프롬프트는 영어 예문의 핵심 행동을 약 8초 안에 이해할 수 있도록 구성한다.

#### 권장 시간 구성

| 구간   | 내용                     |
| ---- | ---------------------- |
| 0~2초 | 인물, 장소, 핵심 사물 소개       |
| 2~6초 | 목표 단어의 의미를 보여 주는 핵심 행동 |
| 6~8초 | 행동의 결과 또는 의미를 강조하는 마무리 |

#### 필수 기준

* 이미지 프롬프트와 동일한 인물, 사물, 장소를 사용한다.
* 예문의 핵심 행동을 분명하게 보여 준다.
* 장면 전환을 지나치게 많이 사용하지 않는다.
* 8초 안에 의미를 이해할 수 있는 단순한 흐름으로 구성한다.
* 화면 속 글자가 필요한 경우 짧고 읽기 쉽게 작성한다.
* 위험하거나 유해한 행동을 구체적으로 묘사하지 않는다.
* 저작권이 있는 고유 캐릭터나 로고를 사용하지 않는다.

### 8.2 수준에 맞는 영영 뜻

사전의 복잡한 정의를 그대로 제공하지 않고, 초등학교 6학년이 이해할 수 있는 쉬운 영어로 영영 뜻을 제공한다.

### 8.3 하나의 예문에서 연결되는 콘텐츠

하나의 영어 예문을 기준으로 다음 콘텐츠를 일관되게 생성한다.

* 영영 뜻
* 영어 예문
* 예문 한글 해석
* 이미지 생성 프롬프트
* 8초 영상 생성 프롬프트

### 8.4 대량 생성에 적합한 흐름

약 1,200개의 단어를 처리할 수 있도록 CSV 입력, 자동 생성, 품질 검토, 재생성 대기 목록 관리 기능을 제공한다.

## 11. 사용자 시나리오

### 11.1 콘텐츠 생성 시나리오

1. 콘텐츠 제작자가 영어 단어와 한글 뜻이 포함된 CSV 파일을 준비한다.
2. CSV 파일을 서비스에 업로드한다.
3. 서비스가 각 단어의 대표 의미와 품사를 결정한다.
4. 관심사 묶음과 학습 묶음을 번갈아 적용한다.
5. 현재 주제가 단어 의미와 맞지 않으면 같은 묶음의 다음 적합한 주제를 선택한다.
6. 쉬운 영영 뜻과 영어 예문을 생성한다.
7. 같은 예문을 기반으로 이미지 생성 프롬프트를 만든다.
8. 같은 장면을 기반으로 8초 영상 생성 프롬프트를 만든다.
9. 생성 결과를 자동 검증한다.
10. 문제가 있는 항목은 품질 검토 또는 재생성 대기 목록으로 이동한다.
11. 콘텐츠 제작자가 결과를 검토하고 필요한 항목을 수정하거나 재생성한다.
12. 최종 결과를 CSV 또는 다른 학습 콘텐츠 형식으로 내보낸다.

### 11.2 학습 시나리오

1. 학습자가 영어 단어와 한글 뜻을 확인한다.
2. 쉬운 영영 뜻을 읽는다.
3. 관심사 또는 학습 주제가 포함된 영어 예문을 읽는다.
4. 예문 한글 해석을 확인한다.
5. 이미지에서 단어가 사용되는 장면을 확인한다.
6. 짧은 영상에서 단어의 행동과 상황을 확인한다.
7. 단어, 문장, 이미지, 영상을 연결해 의미와 사용 맥락을 익힌다.

## 12. 핵심 기능 요구사항

### 12.1 CSV 입력

* 영어 단어와 한글 뜻이 포함된 CSV 파일을 업로드할 수 있어야 한다.
* 필수 열이 누락된 경우 오류를 안내해야 한다.
* 빈 값이나 중복 단어를 확인할 수 있어야 한다.
* 파일 인코딩 문제를 감지하고 안내해야 한다.
* 업로드 전에 일부 행을 미리 볼 수 있어야 한다.

### 12.2 의미 및 품사 결정

* 입력된 한글 뜻을 기준으로 대표 의미를 선택해야 한다.
* 대표 품사를 자동으로 결정해야 한다.
* 선택된 의미와 품사를 결과에 표시해야 한다.
* 의미가 불명확한 항목은 검토 필요 상태로 표시해야 한다.
* 콘텐츠 제작자가 대표 의미와 품사를 수정할 수 있어야 한다.

### 12.3 영영 뜻 생성

* 초등학교 6학년 수준의 쉬운 영어를 사용해야 한다.
* 정의 안에 목표 단어 자체를 반복해서 사용하지 않는 것을 원칙으로 한다.
* 지나치게 추상적이거나 어려운 단어를 피해야 한다.
* 선택된 대표 의미와 품사에 맞아야 한다.

### 12.4 영어 예문 생성

* 목표 단어를 정확히 포함해야 한다.
* 문법적으로 자연스러워야 한다.
* 초등학교 6학년 수준으로 작성해야 한다.
* 배정된 주제를 자연스럽게 반영해야 한다.
* 이미지와 영상으로 표현 가능한 장면이어야 한다.
* 예문 한글 해석을 함께 제공해야 한다.

### 12.5 주제 배정

* 관심사 묶음과 학습 묶음을 번갈아 배정해야 한다.
* 각 묶음 안에서 주제를 순환해야 한다.
* 단어 뜻과 맞지 않는 주제는 건너뛸 수 있어야 한다.
* 건너뛴 주제와 사유를 기록해야 한다.
* 실제 배정된 주제를 결과에 표시해야 한다.

### 12.6 이미지 프롬프트 생성

* 영어 예문의 장면과 일치해야 한다.
* 목표 단어의 의미를 시각적으로 보여 줘야 한다.
* 안전한 장면으로 작성해야 한다.
* 저작권이 있는 고유 캐릭터와 로고를 피해야 한다.
* 이미지 생성 모델에 바로 입력할 수 있는 형태여야 한다.

### 12.7 영상 프롬프트 생성

* 영상 길이는 8초를 기준으로 작성해야 한다.
* 예문의 핵심 행동이 명확하게 표현되어야 한다.
* 이미지 프롬프트와 등장인물 및 배경이 일치해야 한다.
* 시간 흐름과 행동 순서를 포함해야 한다.
* 영상 생성 모델에 바로 입력할 수 있는 형태여야 한다.

### 12.8 품질 검토

다음 항목을 자동으로 검사해야 한다.

* 목표 단어가 예문에 포함되었는지 여부
* 선택한 품사로 사용되었는지 여부
* 입력된 한글 뜻과 예문의 의미가 일치하는지 여부
* 문장 난도가 초등학교 6학년 수준인지 여부
* 문법적으로 자연스러운지 여부
* 예문과 이미지 프롬프트가 일치하는지 여부
* 예문과 영상 프롬프트가 일치하는지 여부
* 주제 배정 순서가 올바른지 여부
* 유해하거나 부적절한 내용이 포함되었는지 여부

### 12.9 재생성 대기 목록

## 14. 리스크 및 대응 방안

### 14.1 단어 의미와 품사의 불확실성

#### 리스크

한글 뜻만으로 단어의 정확한 품사나 여러 의미를 충분히 구분하지 못할 수 있다.

#### 대응 방안

* 입력된 한글 뜻을 가장 우선한다.
* 일반적인 사용 빈도가 높은 의미를 보조 기준으로 사용한다.
* 선택한 의미와 품사를 모든 콘텐츠에 동일하게 적용한다.
* 신뢰도가 낮은 항목은 품질 검토 대상으로 표시한다.
* 콘텐츠 제작자가 의미와 품사를 수정하고 다시 생성할 수 있도록 한다.

### 14.2 주제 배정의 부자연스러움

#### 리스크

특정 단어가 현재 배정된 관심사 또는 학습 주제와 자연스럽게 연결되지 않을 수 있다.

#### 대응 방안

* 부적합한 주제를 억지로 사용하지 않는다.
* 같은 묶음 안에서 다음 적합한 주제를 찾는다.
* 적합한 주제가 없으면 다른 묶음 사용을 허용한다.
* 실제 배정 순서와 건너뛴 사유를 기록한다.
* 주제 건너뛰기 비율이 지나치게 높으면 주제 목록을 조정한다.

### 14.3 유해 콘텐츠 제한

#### 리스크

일부 단어의 의미나 예문 장면이 이미지 또는 영상 생성 모델의 안전 기준에 걸릴 수 있다.

#### 대응 방안

* 핵심 단어의 의미는 유지한다.
* 직접적이거나 자극적인 표현을 은유적이고 안전한 장면으로 바꾼다.
* 사람 대신 동물이나 사물을 활용한 장면으로 대체할 수 있다.
* 폭력, 부상, 위험 행동을 구체적으로 묘사하지 않는다.
* 대체 후에도 생성할 수 없는 경우 실패 사유와 마지막 시도를 재생성 대기 목록에 기록한다.

### 14.4 저작권 및 상표권 문제

#### 리스크

게임이나 애니메이션 관련 예문에서 저작권이 있는 캐릭터, 로고, 게임 화면이 생성될 수 있다.

#### 대응 방안

* 실제 게임 이름이나 고유 캐릭터 이름을 사용하지 않는다.
* 특정 게임의 UI, 로고, 아이템 디자인을 그대로 재현하지 않는다.
* 일반적인 판타지 게임, 블록 게임, 레이싱 게임, 전략 게임 등의 표현을 사용한다.
* 프롬프트 생성 후 고유명사와 브랜드명을 자동 검사한다.

### 14.5 대량 생성 품질 편차

#### 리스크

1,200개 단어를 한 번에 생성하면 문장 난도, 문법, 주제 적합성 등에 품질 편차가 발생할 수 있다.

#### 대응 방안

* 일정한 생성 템플릿을 사용한다.
* 단어별 자동 검증 단계를 적용한다.
* 일정 단위로 나누어 생성하고 품질을 확인한다.
* 실패 유형을 분류해 유형별 재생성 프롬프트를 적용한다.
* 반복적으로 실패하는 항목은 수동 검토 대상으로 전환한다.
