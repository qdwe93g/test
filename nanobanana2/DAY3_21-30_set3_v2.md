# User Image Prompts — DAY 3 · 21–30 · Set 3 (v2 - Optimized for Nanobanana2)

## Global Style & Constraints (Apply to ALL images)

**Art Style:** Stylized 3D game-adventure illustration, playful cinematic, soft lighting, rich colors, appealing characters.

**Output Format:**
- Word images: 1024×1024 (1:1 square)
- Sentence images: 1376×768 (16:9 wide)

**Critical Layout Rule for Sentence Images:**
> **BOTTOM 24% MUST BE EMPTY.** Keep all subjects, faces, hands, objects, and action in the UPPER 76%. The bottom quarter should contain ONLY simple background (floor, ground, road, sky, water) with NO important elements. This space is reserved for captions.

**Universal Prohibitions:** No text, letters, words, numbers, subtitles, logos, watermarks, badges, emblems, or branded surfaces.

**Safety Rule:** If blocked, retry with calm, child-friendly alternatives. Replace sensitive elements (violence, weapons, fear) with peaceful metaphors.

## Key Improvements in v2

1. **Simplified prompts**: Reduced from ~350 chars to ~150 chars per prompt
2. **Clear BOTTOM 24% rule**: Explicitly stated in EVERY sentence prompt with bold emphasis
3. **Removed redundancy**: Eliminated repeated phrases like "plain unbranded surfaces", "generous safe margins"
4. **Concrete scene descriptions**: Each prompt now has specific visual elements instead of abstract instructions
5. **UPPER 76% / BOTTOM 24% split**: Clear numerical division helps model understand spatial constraints
6. **Negative examples**: Each prompt specifies what NOT to place in the bottom area (no feet, no objects, etc.)
