# Exit 8 게임 개발 계획서

## 1. 프로젝트 개요

### 1.1 프로젝트명
- **Exit 8** (웹 기반 심리 호러 퍼즐 게임)

### 1.2 게임 컨셉
- 일본의 유명한 인디 게임 "The Exit 8"을 웹에서 즐길 수 있도록 재현
- 지하철 통로를 배경으로 이상한 점을 찾아내고, 올바른 출구(8번 출구)를 찾는 게임
- 단순한 그래픽과 반복적인 공간에서의 미세한 변화 감지가 핵심 재미 요소

### 1.3 타겟 사용자
- 웹 브라우저로 간편하게 게임을 즐기고 싶은 사용자
- 심리 호러 및 퍼즐 게임을 선호하는 유저
- 짧은 시간 동안 집중해서 플레이할 수 있는 게임을 원하는 유저

---

## 2. 기능 요구사항 (Functional Requirements)

### 2.1 핵심 게임플레이
- **이동 시스템**: 앞/뒤로 이동하며 통로 탐색
- **이상 탐지 시스템**: 각 라운드마다 정상/비정상 상태 랜덤 생성
- **판단 시스템**: 이상 유무에 따라 진행 방향 결정
  - 이상이 없음 → 계속 앞으로 진행
  - 이상이 있음 → 뒤로 돌아서 다시 시작 (같은 라운드 재시작)
- **승리 조건**: 8번 출구에 도달하여 탈출 성공
- **패배 조건**: 잘못된 판단으로 인해 무한 루프 또는 게임 오버

### 2.2 게임 상태 관리
- 현재 라운드 (1~8) 표시
- 이전/다음 라운드 전환
- 게임 시작/재시작/종료 기능
- 승패 결과 화면 표시

### 2.3 그래픽/사운드
- **그래픽**: CSS 와 Canvas 를 활용한 3D 풍의 2.5D 표현
- **애니메이션**: 이동 시 부드러운 전환 효과
- **사운드**: 발자국 소리, 환경음, 이벤트 사운드 (옵션)

### 2.4 UI/UX
- **메인 메뉴**: 게임 시작, 조작법 안내
- **게임 화면**: 
  - 중앙: 게임 뷰 (통로)
  - 하단: 조작 버튼 (앞으로, 뒤로, 이상함/정상)
  - 상단: 현재 라운드 표시
- **결과 화면**: 승리/패배 메시지, 재시작 버튼

## 3. 기술 스택

### 3.1 프론트엔드
- **HTML5**: 구조 및 시맨틱 마크업
- **CSS3**: 스타일링, 애니메이션, 반응형 디자인
- **JavaScript (ES6+)**: 게임 로직, 상태 관리, DOM 조작
- **Canvas API**: 동적 그래픽 렌더링 (옵션)

### 3.2 빌드 도구
- 번들러 사용 안 함 (Vanilla JS 로 단순 구성)
- CDN 기반 라이브러리 최소화

### 3.3 배포
- GitHub Pages 또는 정적 호스팅 서비스 활용 가능

## 4. 게임 디자인 상세

### 4.1 게임 맵 구조
```
[시작] → [라운드 1] → [라운드 2] → ... → [라운드 8] → [탈출]
              ↑           ↑                    ↑
          (이상있음)   (이상있음)            (이상있음)
              ↓           ↓                    ↓
          [다시 시작] [다시 시작]          [다시 시작]
```

### 4.2 이상 현상 예시 (각 라운드별 2~3 개)
1. **포스터 변화**: 벽에 붙은 포스터의 색상/문구 변경
2. **조명 변화**: 형광등 깜빡임, 색상 변경, 꺼짐
3. **바닥 패턴**: 타일 무늬 변형, 얼룩, 균열
4. **사인판**: 출구 번호 표시 변화, 화살표 방향 변경
5. **그림자**: 비정상적인 그림자 형태
6. **낙서**: 벽에突然出现 낙서
7. **물체**: 있어야 할 물건이 없거나,不该 있는 물건이 있음
8. **통로 길이**: 평소보다 길거나 짧게 느껴짐

### 4.3 게임 난이도 설계
- **라운드 1~3**: 명확한 이상 현상 (초보자용)
- **라운드 4~6**: 미묘한 변화 (중급자용)
- **라운드 7~8**: 매우 세밀한 차이 (고급자용)

## 7. 성공 기준

### 7.1 기능적 완성도
- 8 개 라운드 모두 정상적으로 플레이 가능
- 이상 현상이 각 라운드마다 정확하게 작동
- 승/패 조건이 명확하게 처리됨

### 7.2 사용자 경험
- 직관적인 UI 로 별도 설명 없이도 플레이 가능
- 부드러운 애니메이션으로 몰입감 제공
- 모바일/데스크톱 모두에서 문제없이 작동

### 7.3 성능
- 초기 로딩 시간 3 초 이내
- 프레임 드롭 없이 부드러운 동작 (60fps 유지)
- 경량화된 자산으로 빠른 실행
