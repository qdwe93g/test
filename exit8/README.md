# 🚇 Exit 8 - 8 번 출구를 찾아라

웹 브라우저에서 즐기는 심리 호러 퍼즐 게임 "Exit 8"입니다.

## 🎮 게임 소개

지하철 통로를 배경으로 이상한 점을 찾아내고, 올바른 출구 (8 번 출구) 를 찾는 게임입니다.
단순한 그래픽과 반복적인 공간에서의 미세한 변화 감지가 핵심 재미 요소입니다.

## 🕹️ 게임 방법

1. **시작하기**: '게임 시작' 버튼을 클릭합니다.
2. **관찰하기**: 각 라운드에서 통로를 주의 깊게 관찰합니다.
3. **판단하기**:
   - 이상이 없으면 ✅ '이상 없음' 버튼 클릭 (또는 Enter/Space)
   - 이상이 있으면 ⚠️ '이상함!' 버튼 클릭 (또는 Escape/X)
4. **탈출하기**: 8 개의 라운드를 모두 통과하면 탈출 성공!

### 조작법

| 키보드 | 마우스 | 동작 |
|--------|--------|------|
| → / D | '앞으로' 버튼 | 앞으로 이동 (탐색용) |
| ← / A | '뒤로' 버튼 | 뒤로 이동 (탐색용) |
| Enter / Space | '이상 없음' 버튼 | 이상 없다고 판단 |
| Escape / X | '이상함!' 버튼 | 이상하다고 판단 |

> 💡 **팁**: 앞/뒤 버튼은 통로를 탐색하는 용도이며, 실제 진행은 '이상 없음'/'이상함' 버튼으로 판단합니다.

## 🎯 게임 규칙

- **총 8 라운드**: 8 개의 라운드를 모두 통과해야 합니다.
- **라운드 1**: 항상 정상 (튜토리얼)
- **라운드 2-7**: 50% 확률로 이상 현상 발생 (랜덤)
- **라운드 8**: 반드시 이상 현상 발생 (마지막 도전)
- **진행 규칙**:
  - 정답: 다음 라운드로 진행
  - 오답: 게임 오버
- **승리 조건**: 8 라운드를 모두 정확히 통과

## 👻 구현된 이상 현상 목록

현재 **5 가지** 이상 현상이 구현되었습니다:

1. **포스터 변화** 🪧 - 벽에 붙은 포스터의 색상이나 모양이 다릅니다.
2. **조명 깜빡임** 💡 - 천장의 형광등이 비정상적으로 깜빡이거나 색이 다릅니다.
3. **바닥 무늬 이상** 💧 - 바닥 타일의 무늬가 끊기거나 색이 다릅니다.
4. **표지판 오류** 🔀 - 비상구 표지판의 방향이나 문구가 이상합니다.
5. **이상한 그림자** 🌫️ - 출처를 알 수 없는 이상한 그림자가 보입니다.

> 📝 참고: 원래 계획에는 8 가지 이상 현상이 포함되어 있었으나, 현재는 5 가지만 구현되었습니다.

```
│   ├── animations.css      # 애니메이션 스타일
│   └── anomaly-renders.css # 이상 현상 DOM 렌더링 스타일

    ├── main.js             # 게임 진입점
    ├── game.js             # 게임 로직 (Game 클래스)
    ├── renderer.js         # 렌더러 (Renderer 클래스)
    ├── anomaly-registry.js # 이상 현상 레지스트리

```

## 🛠️ 기술 스택

- **HTML5** - 구조 및 시맨틱 마크업
- **CSS3** - 스타일링 및 애니메이션
- **Vanilla JavaScript (ES6+)** - 게임 로직 및 인터랙션
- **DOM 기반 렌더링** - 캔버스 대신 DOM 요소로 이상 현상 표현

## 🚀 실행 방법

### 방법 1: 직접 파일 열기

`index.html` 파일을 웹 브라우저에서 엽니다.

### 방법 2: 로컬 서버 사용 (권장)

```bash
# Python 3 사용
python3 -m http.server 8080

# 또는 Node.js 사용
npx serve .
```

브라우저에서 `http://localhost:8080` 으로 접속합니다.
