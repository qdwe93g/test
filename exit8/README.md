# 🚇 Exit 8 - 8 번 출구를 찾아라

웹 브라우저에서 즐기는 심리 호러 퍼즐 게임 "Exit 8"입니다.

## 🎮 게임 소개

지하철 통로를 배경으로 이상한 점을 찾아내고, 올바른 출구 (8 번 출구) 를 찾는 게임입니다.  
단순한 그래픽과 반복적인 공간에서의 미세한 변화 감지가 핵심 재미 요소입니다.

## 🕹️ 게임 방법

1. **시작하기**: '게임 시작' 버튼을 클릭합니다.
2. **관찰하기**: 각 라운드에서 통로를 주의 깊게 관찰합니다.
3. **이동하기**: 앞/뒤로 이동하며 통로를 탐색합니다.
4. **판단하기**: 
   - 이상이 없으면 ✅ '이상 없음' 버튼 클릭
   - 이상이 있으면 ⚠️ '이상함!' 버튼 클릭
5. **탈출하기**: 8 개의 라운드를 모두 통과하면 탈출 성공!

### 조작법

| 키보드 | 마우스 | 동작 |
|--------|--------|------|
| → / D | '앞으로' 버튼 | 앞으로 이동 |
| ← / A | '뒤로' 버튼 | 뒤로 이동 |
| Enter / Space | '이상 없음' 버튼 | 이상 없다고 판단 |
| Escape / X | '이상함!' 버튼 | 이상하다고 판단 |

## 🎯 게임 규칙

- **라운드 1~8**: 총 8 개의 라운드를 통과해야 합니다.
- **이상 현상**: 일부 라운드에서는 통로에 이상한 점이 발생합니다.
- **진행 규칙**:
  - 이상이 없을 때 '이상 없음'을 선택 → 다음 라운드로 진행
  - 이상이 있을 때 '이상함!'을 선택 → 현재 라운드 재시작
  - 잘못된 판단 → 게임 오버

## 🚀 실행 방법

### 방법 1: 브라우저에서 직접 열기

`index.html` 파일을 웹 브라우저 (Chrome, Firefox, Safari 등) 에서 엽니다.

```bash
# macOS
open exit8/index.html

# Windows
start exit8/index.html

# Linux
xdg-open exit8/index.html
```

### 방법 2: 로컬 서버 사용 (권장)

```bash
# Python 이 설치된 경우
cd exit8
python3 -m http.server 8000

# 그 후 브라우저에서 http://localhost:8000 접속
```

### 방법 3: GitHub Pages 에 배포

1. GitHub 저장소에 푸시
2. Settings → Pages 에서 브랜치 선택
3. 제공된 URL 로 접속

## 🎨 기술 스택

- **HTML5**: 구조 및 시맨틱 마크업
- **CSS3**: 스타일링, 애니메이션, 반응형 디자인
