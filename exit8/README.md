# 🚇 Exit 8 - 8 번 출구를 찾아라

웹 브라우저에서 즐기는 심리 호러 퍼즐 게임 "Exit 8"입니다.

## 🎮 게임 소개

지하철 통로를 배경으로 이상한 점을 찾아내고, 올바른 출구 (8 번 출구) 를 찾는 게임입니다.
단순한 그래픽과 반복적인 공간에서의 미세한 변화 감지가 핵심 재미 요소입니다.

## 🕹️ 게임 방법

1. **시작하기**: '게임 시작' 버튼을 클릭합니다.
2. **관찰하기**: 각 라운드에서 통로를 주의 깊게 관찰합니다.
3. **이동하기**: 앞/뒤로 이동하며 통로를 탐색합니다.
4. **판단하기**:
   - 이상이 없으면 ✅ '이상 없음' 버튼 클릭
   - 이상이 있으면 ⚠️ '이상함!' 버튼 클릭
5. **탈출하기**: 8 개의 라운드를 모두 통과하면 탈출 성공!

### 조작법

| 키보드 | 마우스 | 동작 |
|--------|--------|------|
| → / D | '앞으로' 버튼 | 앞으로 이동 |
| ← / A | '뒤로' 버튼 | 뒤로 이동 |
| Enter / Space | '이상 없음' 버튼 | 이상 없다고 판단 |
| Escape / X | '이상함!' 버튼 | 이상하다고 판단 |

## 🎯 게임 규칙

- **라운드 1~8**: 총 8 개의 라운드를 통과해야 합니다.
- **이상 현상**: 일부 라운드에서는 통로에 이상한 점이 발생합니다.
- **진행 규칙**:
  - 라운드 1: 항상 정상 (튜토리얼)
  - 라운드 2-7: 50% 확률로 이상 현상 발생 (랜덤)
  - 라운드 8: 반드시 이상 현상 발생 (마지막 도전)
  - 정답 시 다음 라운드로 진행
  - 오답 시 게임 오버

## 👻 이상 현상 목록

총 8 가지 종류의 이상 현상이 있습니다:

1. **포스터 변화** 🪧 - 벽에 붙은 포스터의 색상이나 모양이 다릅니다.
2. **조명 깜빡임** 💡 - 천장의 형광등이 비정상적으로 깜빡이거나 색이 다릅니다.
3. **바닥 무늬 이상** 💧 - 바닥 타일의 무늬가 끊기거나 색이 다릅니다.
4. **표지판 오류** 🔀 - 비상구 표지판의 방향이나 문구가 이상합니다.
5. **이상한 그림자** 🌫️ - 출처를 알 수 없는 이상한 그림자가 보입니다.
6. **비상구 문 개방** 🚪 - 닫혀 있어야 할 비상구 문이 열려 있거나 없습니다.
7. **손 등장** ✋ - 벽 사이로 손이 나와 있습니다.
8. **검은 형상** 👤 - 통로 끝에 검은 사람 형상이 서 있습니다.

## 🚀 실행 방법

1. `index.html` 파일을 웹 브라우저에서 엽니다.
2. 또는 로컬 서버를 실행합니다:
   ```bash
   python3 -m http.server 8080
   ```
3. 브라우저에서 `http://localhost:8080` 으로 접속합니다.

## 🧪 테스트 실행

브라우저 콘솔에서 다음 명령을 실행합니다:

```javascript
runTests()
```

총 10 개의 자동화 테스트가 실행됩니다:
- Game 클래스 정의 확인
- 라운드 1 은 항상 정상
- 라운드 설정 랜덤성 확인
- 8 개 라운드 존재 확인
- 라운드 8 에 항상 이상 현상
- 이상 현상 타입 유효성
- ANOMALY_REGISTRY completeness
- normalDescription 존재 확인
- getRandomAnomalyType 검증
- 게임 승리 조건 시뮬레이션
