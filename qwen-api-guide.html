📋 Qwen API 모델 소개

Qwen 은 Alibaba Cloud 에서 개발한 대규모 언어 모델 시리즈로, 다양한 크기와 용도의 모델이 제공됩니다.

Qwen-Max

특징: 가장 강력한 성능을 자랑하는 플래그십 모델로, 복잡한 추론과 고급 작업에 최적화되어 있습니다.

용도: 복잡한 문제 해결, 전문적인 분석, 고품질 콘텐츠 생성

Qwen-Plus

특징: 성능과 비용 효율성의 균형을 맞춘 모델로, 다양한 작업에 적합합니다.

용도: 일반적인 업무 자동화, 고객 지원, 콘텐츠 작성

Qwen-Turbo

특징: 빠른 응답 속도와 낮은 비용으로 실시간 애플리케이션에 이상적입니다.

용도: 실시간 채팅, 빠른 응답이 필요한 서비스, 대량 처리

Qwen-Long

특징: 긴 컨텍스트 윈도우를 지원하여 장문 문서 처리에 특화되어 있습니다.

용도: 장문 문서 분석, 논문 요약, 법률 문서 처리

Qwen-VL (Vision-Language)

특징: 이미지와 텍스트를 동시에 처리할 수 있는 멀티모달 모델입니다.

용도: 이미지 분석, 시각적 질문 답변, OCR 작업

Qwen-Audio

특징: 음성 및 오디오 데이터를 처리할 수 있는 멀티모달 모델입니다.

용도: 음성 인식, 오디오 분석, 음악 이해

  • 일부 고급 기능 사용 불가

💡 토큰 계산 방법

토큰이란?
토큰은 텍스트의 기본 단위로, 일반적으로:
• 영어: 약 4 문자 = 1 토큰
• 한국어: 약 2~3 글자 = 1 토큰
• 예시: "안녕하세요" ≈ 2-3 토큰

📈 과금 예시

예시 1: Qwen-Turbo 사용 시
Input: 5,000 토큰 + Output: 3,000 토큰 = 총 8,000 토큰

계산:
• Input 비용: 5 × $0.002 = $0.010
• Output 비용: 3 × $0.006 = $0.018
총 비용: $0.028
예시 2: Qwen-Max 사용 시
Input: 10,000 토큰 + Output: 5,000 토큰 = 총 15,000 토큰

계산:
• Input 비용: 10 × $0.040 = $0.400
• Output 비용: 5 × $0.120 = $0.600
총 비용: $1.000
